## Warum

Ein Emoji sieht auf jedem Betriebssystem, in jeder Schrift und in jeder
Sprachumgebung anders aus. Ein Symbolsatz gibt eine bestimmte Zeichnung
mit einer Größe und einer Farbe, die man setzen kann.

## Wer das gesagt hat

**der Betreiber, 04.06.2026, wörtlich:** „in diesem projekt keine emojis
verwenden nur lucid icons."

Das steht hier, weil eine Geschmacksregel ohne Urheber beim ersten
Widerspruch weggeräumt wird. Diese hat einen.

## Die Grenze

Code und Oberfläche: keine Emojis. **Prosa nicht** — Einträge, Notizen,
Nachrichten, Markdown-Dokumente. Dort sind sie Text, kein Bauteil.
